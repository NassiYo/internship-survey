# Точка старта — приложение

Учебный опрос и кабинет администратора. Требования: ../specs/001-survey.md; план: ../plan.md.

Node.js >=22.13, npm. Установка: `npm ci`. Проверки: `node --test tests/survey.test.mjs`, `npx tsc --noEmit`, `npm run build`.

Для локального просмотра после сборки примените SQL из drizzle к локальной D1:

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_parched_ronan.sql
npm run dev
```

Локальная авторизация Sites использует тестовую личность, указанную при запуске. Для проверки кабинета задайте её email в ADMIN_EMAILS в игнорируемом файле .dev.vars. Это только локальная имитация; в production используются заголовки идентификации платформы и серверная переменная ADMIN_EMAILS.

Маршруты: /survey, /admin/login, /admin/responses, /admin/statistics. Данные хранятся на сервере в D1. Доступ к чтению проверяется на сервере для каждого запроса. При пустом ADMIN_EMAILS кабинет закрыт.

Сайт сначала опубликован в приватном режиме Sites. Публичный маршрут /survey внутри приложения не отменяет ограничение доступа ко всему сайту платформой. Для реальных участников отдельно настройте аудиторию сайта, срок хранения и информацию о сборе данных.

Диапазон возраста 1–120 — предположение первой версии. Таблица загружает все ответы: для больших объёмов потребуется серверная пагинация. Удаление, экспорт и восстановление анкеты после закрытия вкладки не реализованы.

Проверка после развёртывания: вход разрешённым аккаунтом, отказ другому аккаунту, отправка вымышленной анкеты и её появление в таблице и статистике. Автотесты не заменяют проверку production-авторизации.
