## Локальная проверка на Windows — 15 ноября 2026

Проверена ветка feat/survey-admin после коммита 5e09f70.

- Сохранность после перезапуска сервера — пройдена. Перед остановкой через административный API получены две анкеты: одна завершённая и одна вне целевой аудитории. После двух перезапусков Node/Vinext административный API вернул HTTP 200; полные записи, включая идентификаторы, даты, состояния и ответы, совпали с контрольным снимком. Счётчики: всего 2, завершённых 1, вне целевой аудитории 1.
- Отказ вошедшему пользователю без прав — пройден. Временно из локального ADMIN_EMAILS исключён тестовый аккаунт seedy@sites.test. Запрос GET /api/responses с его локальной сессией вернул HTTP 403. Маршруты /admin/responses и /admin/statistics перенаправили на /admin/login с сообщением «доступ не предоставлен»; данные анкет не выдавались. Проверено HTTP-запросами к локальному серверу.
- После проверки исходный .dev.vars восстановлен, тестовому администратору снова доступен API. Сервер оставлен работающим на http://127.0.0.1:5173. Контрольный снимок и локальные настройки находятся в игнорируемых Git файлах.

Совместная ручная проверка в браузере (результаты подтверждены пользователем):

- Обязательные поля, множественный выбор, уточнение «Другое» и исключительные варианты работают.
- Город требуется для очного формата, скрывается для удалённого и не сохраняется после скрытия.
- Завершённая анкета сохраняется и доступна в кабинете; анкета вне целевой аудитории содержит только первые три ответа и не влияет на диаграммы.
- Поиск без учёта регистра, пустой результат, сброс и совместное применение фильтров работают; общие счётчики не зависят от фильтров.
- Пять диаграмм соответствуют ответам завершённой анкеты.
- Без входа таблица и статистика перенаправляют на вход; после повторного входа и обновления анкеты доступны.
- Окно анкеты блокирует элементы позади, закрывается при нажатии вне окна; кнопка закрытия остаётся видимой при прокрутке. Исправление подтверждено пользователем.
- При уменьшении окна до узкой ширины поиск, фильтры, горизонтальная прокрутка таблицы и окно анкеты доступны. Это проверка узкого окна настольного браузера, а не отдельного мобильного устройства.
