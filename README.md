# Учебный проект: сайт-опросник

Цель — освоить spec-driven development на небольшом приложении, которое принимает ответы через сайт, сохраняет их на сервере и показывает в таблице.

## Как работаем

1. Уточняем требования в specs/001-survey.md.
2. Превращаем согласованные требования в технический план.
3. Разбиваем план на небольшие проверяемые задачи.
4. Реализуем задачи и проверяем критерии приёмки из спецификации.
5. Если поведение меняется, сначала обновляем спецификацию, затем код и проверки.

Спецификация описывает наблюдаемое поведение. План объясняет, как его реализовать. Задачи определяют порядок работы. Проверки подтверждают выполнение требований.

Сейчас подготовлен черновик спецификации. Технологии и хостинг пока не выбраны: сначала уточняем сценарии.
