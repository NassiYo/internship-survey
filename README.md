# Точка старта — опрос для подбора стажировок

Учебный проект по spec-driven development: сайт собирает ответы студентов и выпускников вузов, сохраняет их на сервере и предоставляет администратору таблицу и статистику.

## Документы проекта

- [Спецификация](specs/001-survey.md) — вопросы, правила поведения и критерии приёмки.
- [Технический план](plan.md) — архитектура, хранение данных и доступ.
- [Задачи](tasks.md) — последовательность реализации.

## Выбранные технологии

- React / Vinext — форма и кабинет в одном приложении.
- Cloudflare Workers — серверная обработка запросов.
- Cloudflare D1 — постоянное хранение анкет.
- Sites — размещение приложения.
- Вход администратора через ChatGPT; серверный список ADMIN_EMAILS определяет доступ.

## Страницы

- `/survey` — опрос без отдельной регистрации в приложении.
- `/admin/login` — вход администратора.
- `/admin/responses` — таблица, фильтры и полная анкета.
- `/admin/statistics` — счётчики и диаграммы.

Учебная версия: https://internship-survey-lab.stoutmarmot1.chatgpt.site/survey

Сейчас весь сайт ограничен владельцем на уровне Sites. Доступ внешних участников к опросу ещё не открыт. Публичный репозиторий с исходниками не предоставляет доступа к ответам.

## Как работаем

1. Сначала уточняем поведение и критерии в спецификации.
2. Обновляем технический план и задачи.
3. Реализуем изменение в отдельной ветке.
4. Проверяем результат по критериям приёмки.
5. Оформляем pull request для просмотра и решения о слиянии.

PR №1 содержит документацию. Реализация находится в отдельном PR №2; файлы приложения появятся в основной ветке после его слияния. Инструкции запуска находятся в README приложения в PR №2. Публикация учебной версии и слияние кода в main — отдельные действия.

Диапазон возраста и условия сбора реальных данных остаются открытыми решениями в спецификации.
