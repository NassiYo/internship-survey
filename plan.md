# Технический план 001

Форма и кабинет — одно приложение React/Vinext. Серверный обработчик проверяет данные и сохраняет запись в постоянной базе Cloudflare D1. Схема меняется миграциями.

Маршруты соответствуют спецификации. POST /api/responses принимает анкету; GET /api/responses возвращает данные только администратору. Страницы кабинета также защищены на сервере. Ответы кабинета не кешируются.

Вход — через ChatGPT, доступ — по явно заданному серверному списку ADMIN_EMAILS. Отсутствие списка закрывает доступ всем. Секреты не попадают в клиентский код. Сайт Sites сначала приватный: открытие опроса внешним участникам — отдельная настройка аудитории.

В записи хранятся уникальный идентификатор отправки, время, состояние и проверенные ответы JSON. Повторная отправка с тем же идентификатором не создаёт дубль.

Правила полей общие для интерфейса и сервера; сервер — окончательная проверка. Скрытые значения исключаются. Статистика вычисляется из завершённых анкет, незавершённые считаются отдельно.

Для первой реализации диапазон возраста 1–120 остаётся явно отмеченным предположением. Применение фильтров и графиков — в браузере после защищённой загрузки; при росте объёма добавить серверную пагинацию.

Проверки: несовместимые ответы, условные поля, лимиты текста, исключённые участники, идемпотентность, запрет доступа без административной роли, сборка и проверка интерфейса, если доступен локальный просмотр.
